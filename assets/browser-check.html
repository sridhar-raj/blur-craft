blur-craft browser check

Each box should make the stripes and the letters behind it soft. If they're as sharp inside the box as outside, that case doesn't blur in this browser.

1. Unprefixed, literal

Chrome, Firefox, Safari 18+ on macOS 15/26: soft. Safari 18/26 on Sonoma: reported sharp (WebKit 297620).

2. Prefixed only, literal

Safari (all): soft. Chrome and Firefox ignore the prefix: sharp is expected there.

3. Both, unprefixed first (blur-craft's order)

Should be soft everywhere. The key Sonoma test: if this is soft and 4 is sharp, the order matters there.

4. Both, prefixed first (Autoprefixer's order)

Soft in Chrome, Firefox and newer Safari. On Sonoma: unknown; compare with 3.

5. var() radius, both

Sonoma Safari 18/26: reported sharp. Elsewhere soft.

6. var() holding the whole filter

Sonoma Safari 18/26: reported sharp. Elsewhere soft.

7. Tailwind v4 compiled shape

Same as 5/6: Sonoma Safari sharp, elsewhere soft.

8. Masked (the extended-backdrop nav bar)

Soft at the top, fading to sharp at the bottom, everywhere.

9. blur-craft material (glass--regular)

Should be soft everywhere, Sonoma included. This is what the skill ships.

10. Backdrop root (parent at opacity .99)

Expected sharp/flat everywhere (spec: the faded parent becomes the backdrop root). If this blurs, the browser doesn't follow the spec.

Report what you see (tile numbers that are sharp) with the browser and macOS version. Source: github.com/sridhar-raj/blur-craft
