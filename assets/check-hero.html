What you should see

This is the Tabula hero from the OriginKit X posts, rebuilt over its own Caustic Weave wallpaper. Each numbered surface uses one way of writing glass. Frosted means the stripes behind it go soft; sharp means you can still see crisp stripes through it, so that technique doesn't blur in this browser.

What's measured: in Chrome, the fixed view really blurs every surface (the Versions panel and the Shortcuts card go from no blur to blurred). Firefox and Safari 18+ are green because those browsers document support for the unprefixed property, not because they were tested here.

One more Safari trap, not shown as a column: Safari on macOS Sonoma (18 and later, Technology Preview included) drops blur written with var() (WebKit bug 297620), and Tailwind v4's backdrop-blur-* is written that way. blur-craft writes literal values to avoid it.

Anything that doesn't match the table is a finding: note the number, the browser and its version (Safari's user agent always says macOS 10_15_7, so check → About This Mac for the real macOS version).
